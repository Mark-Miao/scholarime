# Citation Style Assets

These CSL files are third-party assets under Creative Commons Attribution-ShareAlike 3.0. They are
not relicensed under Scholarime's CC BY-NC-SA 4.0 project license.

Scholarime uses these CSL files for APA 7 and GB/T 7714-2025 reference lists and keeps the built-in
formatter as a fallback. The files are distributed as third-party assets.

Expected files:

- `apa.csl`
- `gbt7714-2025-numeric.csl`

Do not substitute the 2015 GB/T style for the requested 2025 file without telling the user.
